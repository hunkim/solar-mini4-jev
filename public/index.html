1. Upstage API 키 받기

  1. Upstage Console에 로그인
  2. API Keys에서 키 발급
  3. 아래 요청 헤더에 넣기 (서버에 저장하지 않음 · BYOK)

헤더 중 하나만 있으면 됩니다: X-Upstage-Api-Key 또는 Authorization: Bearer …

2. System One API 호출 예

curl -s https://solar-mini4-jev.vercel.app/v1/systemone \
  -H "Content-Type: application/json" \
  -H "X-Upstage-Api-Key: $UPSTAGE_API_KEY" \
  -d '{
    "model": "solar-mini4-jev",
    "state": "Payment success rate dropped to 12%.",
    "questions": {
      "urgent": {
        "type": "noul",
        "instructions": "Should on-call be paged immediately?"
      }
    }
  }'

응답 필드: model, answers, usage, latency_s (Jev System One과 동일 형태)

3. Bearer 헤더 예

curl -s https://solar-mini4-jev.vercel.app/v1/systemone \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $UPSTAGE_API_KEY" \
  -d '{
    "model": "solar-mini4-jev",
    "state": "고객이 환불을 세 번 요청했습니다.",
    "questions": {
      "refund": {
        "type": "noul",
        "instructions": "즉시 환불 처리가 필요한가?"
      },
      "urgency": {
        "type": "score",
        "instructions": "긴급도 0~1"
      }
    }
  }'
